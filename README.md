# Market-Sentiment-Analysis
A bit of python code to parse sentiment and Market open and close values on the Hang Seng Index taken at irregular times (with inbuilt Imputation for unavailable data) that allows comparison of Market dynamics and Sentiment
The code takes advantage of library files such as Pandas, numpy and mathplotlib and was originally written in Jupyter notebook (I could not be bothered to change it from .ipynb format but that should not be much of an issue)
You don't really need any special tools beyond the library files to try and run my code here, and i welcome anyone who wishes to fork it for improvement.
